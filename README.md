Beneficios de usar um recurso de Banco de Dados no Azure: 
Ter um espaço online organizado para guardar informações.
Poder criar diferentes "pastas" (tabelas) para separar os tipos de informação.
Conseguir adicionar, modificar e encontrar informações de forma fácil e rápida, sem precisar folhear páginas ou procurar em vários arquivos.


Em resumo: 📚
🎲 Para um estudante, isso pode ser usado para guardar dados de projetos, informações de trabalhos da faculdade, listas de livros, etc. É uma forma de aprender a organizar e acessar informações de maneira eficiente usando a tecnologia da nuvem. E o melhor é que, com a conta de estudante, você pode experimentar tudo isso sem ter que pagar no início!
